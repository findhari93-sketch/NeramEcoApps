Design audit @neram/marketing · neramclasses.com · 15 Oct 2026

One site, five visual languages

The homepage is built on a dark "aiArchitek" theme that no other page uses. Every other page falls back to the default light MUI theme, then overrides colours and fonts inline, page by page. This audit lists the gaps file by file, then sets out one token layer and a migration order.

04 — Findings

F1
The homepage runs on its own themeHigh

A nested ThemeProvider swaps in neramaiArchitekDarkTheme, so primary.main, text.secondary and h2 resolve to different values on Home than on every other page. Header and Footer are shared, and the Footer is hard-coded dark navy/gold. Inner pages therefore go light body → dark footer, with no dark section at the top to match it.

HomePageContent.tsx:141 · Footer.tsx:107 (bgcolor #030812) · [locale]/layout.tsx:175
F2
Code comments no longer match the theme setupMedium

NewHeroSection says it "wraps itself in a nested ThemeProvider so the rest of the page stays on the existing marketing light theme". It doesn't. The wrapper sits in HomePageContent and covers the whole page. Anyone reading the hero code will assume the wrong scope.

hero/NewHeroSection.tsx:19–23
F3
Type is set inline, per pageHigh

Six font stacks are in use: Inter (body), Museo (logo), Poppins/Plus Jakarta Sans (NATA sections), a theme serif (Nexus showcase), and four different monospace strings. The home eyebrow stack "SFMono-Regular", "Cascadia Code"… is pasted in 14 places. The page H1 also changes each time: Home 3.5rem/1.05, Coaching 3.5rem/700, Fees is an h3 at 2.5rem/800, About is an h2.

HomePageContent.tsx:158,220,341,441 · hero/*.tsx · nata/sections/HeroSection.tsx:205 · apply/showcase/palette.ts:30
F4
Hard-coded colours bypass the themeHigh

Five blues, six golds and five navies appear as literals (see 02). The Header's CTA states use hard-coded #2E7D32, #90CAF9 and white alpha values. These were written for a dark header and don't adapt to a light one. A palette change in @neram/ui won't reach any of them.

Header.tsx:78–132 · CoachingPageContent.tsx:114,134,314 · Footer.tsx:101–428 · AboutPageContent.tsx AVATAR_COLORS
F5
The homepage's section pattern exists only as copied codeHigh

Each homepage section is built the same way: mono eyebrow, then centred h2, then a lede capped at 480–560px, then a grid. It's written out by hand each time, in HomePageContent, Testimonials, SocialProof and StudentResultsTeaser. Inner pages never picked it up, so the strongest part of the homepage hasn't spread to other pages. SectionDivider (the gold diamond) is also used on Home only.

HomePageContent.tsx:155–185, 217–246, 338–366 · SectionDivider.tsx · TestimonialsPageContent.tsx:484,799
F6
Two icon systemsMedium

Homepage tool cards and floating hero badges use emoji (🧮 🎓 📍 ✂️ 🎯 📚). The Header, Fees and Contact pages use MUI outlined icons. Emoji also render differently on Android, iOS and Windows, and ~60% of traffic is mobile.

HomePageContent.tsx:72–90 · hero/NewHeroSection.tsx:181–203 · Header.tsx:28–47
F7
The homepage breaks the team's own mobile rulesMedium

The project's CLAUDE.md requires a 16px base font. The hero subhead is 13px on phones and the primary CTA label is 12px. The tool cards use backdropFilter: blur(12px) plus radial gradients, which are costly to render on low-end Android against the LCP-under-2.5s-on-3G target.

hero/NewHeroSection.tsx:115,151 · HomePageContent.tsx:262–275 · CLAUDE.md "Mobile-first rules"
F8
Global CSS is half light, half darkMedium

globals.css sets body to #FAFBFC/#1A2027 and the loading spinner and focus ring to Material blue. In the same file, --neram-* variables and the .neram-glass and .neram-blueprint-bg utilities are dark-only. Home shows a light flash and blue spinner before the dark page paints.

styles/globals.css:7–18, 70–76, 118–121, 133–156, 230–260
F9
Small inconsistencies that add upLow

The same tools link to two URL schemes: /tools/cutoff-calculator in the tool cards and /tools/nata/cutoff-calculator in the hero badges. Leftover .tsx.tmp.* files and HeroLegacy.tsx are still in components/. Section alternation uses grey.50 bands on About and gold dividers on Home.

05 — Recommendation: make the homepage the system

The homepage is the most deliberate design on the site, so don't rebuild it. Turn it into the system. Keep one set of brand tokens with two surfaces: a dark band for the hero, CTA strip and footer, and a light body for long-form SEO content, which reads better light. Every page then opens dark, reads light and closes dark, so it feels like the homepage without forcing 200+ content pages into dark mode.

Tokens One source: neramTokens

navy 900/800/700 (#060d1f, #0b1629, #122040) · paper #f5f0e8 · gold 500/300 · blue 500 for links and focus · success green · neutral ramp for the light body. Remove every other hex.

Themes Two themes built from those tokens

Rebuild marketingLightTheme and neramaiArchitekDarkTheme from the shared tokens and one type scale. Remove the nested provider on Home. Dark becomes a <Surface tone="dark"> wrapper around a section, not a whole-page theme.

Type Inter + one mono + Museo for the logo

Drop Poppins and the serif. Add an eyebrow variant to the theme (mono 11px, 0.2em, 700). One H1 scale on every page: 2 / 2.5 / 3.5rem, line-height 1.05. Body never below 16px on mobile.

06 — Rollout order

PHASE 1Tokens + globals

Consolidate hexes into neramTokens. Retheme globals.css (spinner, focus, selection). Delete the .tmp files. No visual change on Home.

PHASE 2Extract components

Extract SectionHeader, PageHero, CtaButton and Surface. Refactor Home to use them, with no visual diff. Header CTA reads from tokens.

PHASE 3Top-traffic pages

Coaching, Courses, Fees, About, Apply. Each gets a dark PageHero, light body and the shared SectionHeader.

PHASE 4SEO templates

nata-2026/*, counseling/*, colleges/*, aat/pgeta. Fixing the shared layouts updates hundreds of URLs at once. Lint rule: no hex literals in sx.
