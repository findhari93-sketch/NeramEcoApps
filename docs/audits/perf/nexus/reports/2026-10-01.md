## Scope and coverage
- **Approach:** a targeted cost audit (checks NET, CACHE, API, DB, TBL, BND), not a unit-by-unit ledger pass, so no units were recorded and coverage figures are unchanged.
- **Evidence:**
  - Code reading across all four apps and the shared packages.
  - Next 14.2.21 source (`patch-fetch.js`, `app-route/module.js`).
  - curl against production marketing pages (sizes, headers).
  - Staging SQL checks.
  - Read-only row counts on prod.
- **Not available:** per-project Vercel usage. The Vercel MCP token returns 403 for the team scope, so per-project split was not measured.

**Platform changes:**
- Node `22.x` engines in admin, app and marketing; GitHub Actions jobs on Node 22. The Vercel banner says Node 20 builds fail from Oct 1, 2026.
- `regions: ["sin1"]` for admin and marketing, next to Supabase.

**Considered and dropped:**
- Per-route `memory: 1024` in `vercel.json`. Vercel splits bundles by function config, and with Fluid compute CPU scales with memory, so the saving (about $0.60) is not worth slower routes.

## Deploy checklist (user actions)
1. **Cloudflare media Worker:**
   - `cd cloudflare/media-proxy && npm i`
   - `npx wrangler secret put VIDEO_TOKEN_SECRET`, equal to Nexus `VIDEO_STREAM_SECRET`, or `IMPERSONATION_JWT_SECRET` if that is unset.
   - `npx wrangler secret put MEDIA_PROXY_SECRET`, a new random value.
   - Do both for `--env staging` and `--env production`.
   - DNS: proxied records or Worker custom domains for `media` and `media-staging`.
   - Deploy staging first and play a recording; the 206s must come from media-staging.
2. **Nexus Vercel env:**
   - `MEDIA_PROXY_SECRET`
   - `MEDIA_PROXY_ORIGIN`: `https://media.neramclasses.com` for prod, `https://media-staging.neramclasses.com` for preview. Set it only after step 1 works; unset it to roll back.
3. **`REVALIDATE_SECRET`:** the same value in marketing and admin, production and preview.
4. **`SUPABASE_SERVER_URL` (optional, server-only):**
   - The direct `*.supabase.co` for each environment, in all four projects.
   - Check staging first. Unset it to roll back.
5. **Migrations** `20261026090000_admin_aggregate_rpcs.sql` and `20261026090100_nexus_attendance_counts.sql`:
   - They go through `db push`.
   - Confirm they applied on prod, because `db push` uses continue-on-error.
   - The code falls back if they are missing, except admin student-matches.
6. **Vercel dashboard:**
   - Turn off or sample Observability Plus.
   - Turn on Bot Protection and block Bytespider and CCBot on marketing.
   - If bot protection challenges Cloudflare IPs, allowlist `/api/media/recording/source` on Nexus.
7. **Cloudflare cache rule on marketing HTML:** it forces `public, max-age=7200` and ignores `Vary: RSC`. Either bypass it for HTML or add `RSC` and `_rsc` to the cache key.
