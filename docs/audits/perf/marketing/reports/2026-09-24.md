# Marketing performance audit, 2026-09-24

First audit of `apps/marketing` (neramclasses.com). Performance, reliability, API correctness and technical SEO were covered. The keyword and ranking plan built on these findings is in `agents/seo-aeo/nata-coaching-ranking-strategy.md`.

## Scope and coverage
- Planned: the whole app (402 units). Audited: 99 units.
  - All 80 route handlers on ERR-1, ERR-4, API-1, API-3, API-4 and CACHE-1.
  - 15 pages (home, the NATA coaching city/state/online pages, colleges, NATA 2026 hub, apply, the slug detail pages) on HYD, BND-2 and BND-3.
  - 3 layouts (`.`, `[locale]`, `[locale]/nata-2026`) on HYD, BND-2, BND-3, ERR-3 and DUP-1.
  - `config:marketing` on PROD-1.
- Skipped as fresh: 0 (first audit). Deferred: 303 units, mostly exam, counselling, tools and college spoke pages. These are static content pages that share the audited layout.
- Re-audits: none.
- Coverage after this session: 99 of 402 units have an audit record; 303 never audited.
- Evidence sources used:
  - Code reading by three parallel passes (API routes, rendering/bundle, SEO).
  - Live `curl` of neramclasses.com on 2026-09-24 for the SEO findings marked measured.
  - Not run: `next build` (dev servers may be running; the build clobbers `.next`), HAR capture, `pg_stat_statements`, PageSpeed. Every latency and bundle number below is therefore "not measured" unless stated.

## Performance audit report

1. **Top problems, worst first**
   1. PERF-0001, PERF-0002, PERF-0003: security gaps in payment, document storage and enrolment links (redacted; the repo is public).
   2. PERF-0004: all 22 state coaching pages are broken live (canonical `/coaching/nata-coaching-in-undefined`).
   3. PERF-0005: no Razorpay webhook, so a dropped browser loses the payment status.
   4. PERF-0010: robots.txt blocks `/_next/`.
   5. PERF-0014: three competing city page systems cannibalise "NATA coaching in {city}".
   6. PERF-0015: hard-coded self-serving review ratings in schema.
   7. PERF-0017: Firebase, Fuse plus the search index, and Tawk on every page.
   8. PERF-0016: 3 uncached marketing-content fetches per page view, plus banner layout shift.
   9. PERF-0018: LCP hero at opacity 0 until hydration on /nata-2026 (and the home h1 fades in).
   10. PERF-0011, PERF-0012, PERF-0013: live 404s (a Chennai page, 40 sitemap course URLs, the logo and default OG image).
2. **Production errors reported by the user:** none were reported. A likely React #418 on `/colleges` hard loads is PERF-0027 (inferred, not reproduced).
3. **Failing or slow endpoints named by the user:** none named.
4. **Why refresh fixes it:** does not apply.
5. **Slowest APIs** (p50/p95 not measured for any route):
   - `/api/chat` and the four other Gemini routes: no deadline (PERF-0021).
   - `/api/youtube/channel-stats`: three Google calls per view (PERF-0020).
   - `/api/payment/verify`: Razorpay fetch plus inline email/WhatsApp (PERF-0035).
6. **Duplicate requests**

   | Endpoint | Calls per page view | Expected | Cause |
   |---|---|---|---|
   | `/api/marketing-content` | 3 (inferred) | 0 (server-rendered) | BroadcastBanner, ImportantDateBanner and StickyAchievementWidget each fetch it (PERF-0016) |
   | Supabase in `generateMetadata` plus the page | 2 | 1 | No React `cache` on contact, careers, achievements and colleges state (PERF-0043) |

7. **Largest components and bundles**
   - First-load JS not measured.
   - Largest files:
     - `EnrollWizard` 1553 lines
     - `nata-online-coaching/page` 1408
     - `PaymentDialog` 1208
     - `Header` 1169 (client; eager SearchDialog)
   - Global client weight: PERF-0017 and PERF-0038 (full translation bundle in every page).
8. **Database and query bottlenecks:**
   - `/colleges*` render per request with `count: 'exact'` (PERF-0019).
   - The sitemap makes 4 sequential queries per request (PERF-0040).
   - `select('*')` on `getCollegeBySlug` (6 queries) and on marketing content.
   - DB plans not measured.
9. **Most expensive renders:** ImportantDateBanner re-renders every second (LOW, not filed). Framer-motion runs on every NATA 2026 spoke through SpokeNavSidebar.
10. **Recommended fixes, by owner:** marketing app for everything except these three:
    - PERF-0017: `@neram/auth` subpath export (architect).
    - PERF-0021: `@neram/ai` timeout (architect).
    - PERF-0002: storage migration (architect, with Nexus, which reads proofs).
11. **Estimated impact:** see each finding's `expected`. The largest wins:
    - SEO: PERF-0004, 0010, 0014 and 0015 unblock ranking for every state and city.
    - Performance: PERF-0016 and 0017 affect every page view.
12. **Risk:**
    - Medium: payment changes (PERF-0001, 0005), city 301s (PERF-0014), the AuthProvider import change (PERF-0017).
    - Everything else is low.
13. **Implementation order**
    1. Security: PERF-0001, 0003, 0006, 0007, 0008 (code only).
    2. Live SEO breakage: PERF-0004, 0010, 0011, 0012, 0013, 0029.
    3. Payments reliability: PERF-0005, 0023, 0034.
    4. Global performance: PERF-0016, 0017, 0018, 0038, 0027.
    5. SEO consolidation: PERF-0014, 0015, 0030, 0031, 0041.
    6. The rest.
14. **Needs approval before doing:**
    - PERF-0002: make the documents bucket private (migration; Nexus and Admin read it).
    - PERF-0005: webhook secret in Vercel and the Razorpay dashboard.
    - PERF-0014: which city URL system survives (301s).
    - PERF-0036: unique index on applications.
    - PERF-0039: function region change.
15. **Fixed this session:** none. This session was audit only.
