# Ads ROI Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An Admin page that shows, per month of Google Ads spend, how many sign-ups, demos, joined students and rupees of fees that spend brought back.

**Architecture:**
- **Pure counting core:** `lib/marketing-ai/roi.ts`.
- **Database loader:** `lib/marketing-ai/roi-store.ts`. It does the joins in pages and chunks, and reads typed or live spend.
- **Two admin-only routes:** `GET /api/marketing-ai/roi` and `PUT /api/marketing-ai/roi/spend`.
- **One client page:** `/marketing-ai/roi`.
- **One data migration:** adds a "Google ad" answer to the existing onboarding question.

**Tech Stack:** Next.js 14 App Router (apps/admin), Supabase via `getSupabaseAdminClient`, MUI v5 through `@neram/ui`, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-14-ads-roi-design.md`

## Global Constraints

**Attribution**
- Two tiers, never summed into one number:
  - `confirmed`: `isGoogleAdsTouch(users.first_touch)`
  - `said_google_ad`: the onboarding `referral_source` answer is `google_ad`
- A plain `google` answer is never credited. It only feeds `alsoSaidGoogle` for the month.
- Cohort month (IST, `YYYY-MM`):
  - `confirmed`: `first_touch_at`, falling back to `created_at`
  - `said_google_ad`: `created_at`
- Report window: from `2026-01` (`ROI_FROM_MONTH`) to the current IST month.

**Sources**
- Fees come only from `payments` with `status = 'paid'`, de-duplicated by payment id. Never from `direct_enrollment_links.amount_paid` or `student_profiles.fee_paid`.
- A demo counts as booked unless its status is `cancelled` or `rejected`. It counts as attended when `attended === true`.
- Phone matching uses the last 10 digits. Prod stores `+91XXXXXXXXXX` (1,508 rows) and bare 10 digits (42 users, all 5 demos), so `.in('phone', …)` queries use `[p10, '+91'+p10, '91'+p10]`.
- Only real prospects count: `isRealProspect` (no staff, no e2e accounts) and `phone_verified = true`.

**Spend**
- Typed spend lives in `marketing_ai_settings` under key `spend_manual`, as `{ "YYYY-MM": rupees }`. The table only has `PRIMARY KEY (key)`, so no migration is needed.
- `saveSettings` only writes `SETTINGS_KEYS`, so it never overwrites this key.
- Live spend replaces typed spend only when `GOOGLE_ADS_MODE=live` and the customer is not the sample account `1234567890`. It uses campaign-level rows.

**Rules**
- PostgREST returns at most 1,000 rows per request, so lists are paged with `.order('id').range()`. `.in()` lists are chunked at 100 values.
- Phone numbers leave the API only as the last 4 digits.
- Routes are admin only via `requireAdminRole`. Spend changes write audit event `spend_manual_set`.
- Copy rules: no em dashes and no double dashes in any user-visible text. Run `/ui-ux-pro-max` before the page is built and review it after. Keep the `@neram/ui` theme; Admin is desktop-first.
- Tests: `npx vitest run <path>` from the repo root (`pnpm test` is watch mode).
- **Never deploy, push or `git stash`.** Commit only the files of the task, using `git commit <paths>`, because other sessions share the tree.

## Review Focus

1. **The same person under two user rows** (a Google sign-in, then a phone-only account made by staff): fees must be counted once, against the first credited row. Pinned in Task 2.
2. **A payment linked by both `user_id` and `student_profile_id`:** it must count once. Pinned in Task 2.
3. **A confirmed user who also answered `google_ad`:** counted only as confirmed. Pinned in Task 1.
4. **Typed spend for a month with live API spend:** the live value wins and the source shows "from Google". Sample-account rows never count. Pinned in Task 2.
5. **An empty month or zero spend:** return per ₹1 is `null`, never `Infinity` or `NaN`. The page shows "No spend entered". Pinned in Task 1 and Task 4.

// apps/admin/src/lib/marketing-ai/roi.ts
/**
 * Ads ROI: what each month of Google Ads spend brought back, counted from
 * Neram's own database. Spec: docs/superpowers/specs/2026-10-14-ads-roi-design.md.
 *
 * Pure. roi-store.ts gathers people and spend; this file only counts. Two tiers
 * stay apart and are never summed: 'confirmed' (an ad click id on the account)
 * and 'said_google_ad' (the student's own onboarding answer). Credit goes to
 * the month of the first ad click (the sign-up month for an answer), so fees
 * paid months later still land on the month whose spend bought the click.
 */

export type RoiTier = 'confirmed' | 'said_google_ad';
export type RoiStage = 'signed_up' | 'demo_booked' | 'demo_attended' | 'joined';

export interface RoiPerson {
  userId: string;
  name: string | null;
  phone10: string | null;
  tier: RoiTier;
  /** YYYY-MM in IST. */
  cohortMonth: string;
  demoBooked: boolean;
  demoAttended: boolean;
  joined: boolean;
  /** Rupees, from paid payments only. */
  feesPaid: number;
}

export interface TierCounts {
  confirmed: number;
  said_google_ad: number;
}

export interface SpendEntry {
  amount: number;
  source: 'manual' | 'google';
}

export interface RoiPersonView {
  userId: string;
  name: string | null;
  phoneLast4: string | null;
  tier: RoiTier;
  stage: RoiStage;
  feesPaid: number;
}

export interface RoiRow {
  spend: number | null;
  signups: TierCounts;
  demosBooked: TierCounts;
  demosAttended: TierCounts;
  joined: TierCounts;
  fees: TierCounts;
  /** Fees per rupee spent: confirmed only, and confirmed plus said_google_ad. Null without spend. */
  returnPerRupee: { confirmed: number; withSaid: number } | null;
  /** Plain "Google Search" answers in this month: shown, never credited. */
  alsoSaidGoogle: number;
}

export interface RoiMonth extends RoiRow {
  month: string;
  spendSource: SpendEntry['source'] | null;
  people: RoiPersonView[];
}

export interface RoiReport {
  months: RoiMonth[];
  total: RoiRow;
}

/** Ad click ids were first stored in October 2026; earlier months only read 0 confirmed. */
export const ROI_FROM_MONTH = '2026-01';
const IST_MS = 5.5 * 3600 * 1000;

export function istMonth(iso: string): string {
  return new Date(Date.parse(iso) + IST_MS).toISOString().slice(0, 7);
}

export function phone10(raw: string | null | undefined): string | null {
  const d = String(raw ?? '').replace(/\D/g, '');
  return d.length >= 10 ? d.slice(-10) : null;
}

/** The stored forms of one number, for an exact .in() match. Prod holds '+91…' and bare 10 digits. */
export function phoneVariants(p10: string): string[] {
  return [p10, `+91${p10}`, `91${p10}`];
}

export function monthsBetween(from: string, to: string): string[] {
  const out: string[] = [];
  let [y, m] = from.split('-').map(Number);
  const [ty, tm] = to.split('-').map(Number);
  while (y < ty || (y === ty && m <= tm)) {
    out.push(`${y}-${String(m).padStart(2, '0')}`);
    m += 1;
    if (m > 12) {
      m = 1;
      y += 1;
    }
  }
  return out;
}

export function furthestStage(p: RoiPerson): RoiStage {
  if (p.joined) return 'joined';
  if (p.demoAttended) return 'demo_attended';
  if (p.demoBooked) return 'demo_booked';
  return 'signed_up';
}

const zero = (): TierCounts => ({ confirmed: 0, said_google_ad: 0 });
const round2 = (n: number) => Math.round(n * 100) / 100;

function emptyRow(): RoiRow {
  return { spend: null, signups: zero(), demosBooked: zero(), demosAttended: zero(), joined: zero(), fees: zero(), returnPerRupee: null, alsoSaidGoogle: 0 };
}

function addPerson(row: RoiRow, p: RoiPerson) {
  row.signups[p.tier] += 1;
  if (p.demoBooked) row.demosBooked[p.tier] += 1;
  if (p.demoAttended) row.demosAttended[p.tier] += 1;
  if (p.joined) row.joined[p.tier] += 1;
  row.fees[p.tier] += p.feesPaid;
}

function setReturn(row: RoiRow) {
  row.returnPerRupee =
    row.spend && row.spend > 0
      ? { confirmed: round2(row.fees.confirmed / row.spend), withSaid: round2((row.fees.confirmed + row.fees.said_google_ad) / row.spend) }
      : null;
}

export function buildRoi(people: RoiPerson[], spend: Record<string, SpendEntry>, alsoSaidGoogle: Record<string, number>, months: string[]): RoiReport {
  const byMonth = new Map<string, RoiMonth>();
  for (const month of months) {
    const s = spend[month];
    const has = !!s && s.amount > 0;
    byMonth.set(month, { month, ...emptyRow(), spend: has ? s.amount : null, spendSource: has ? s.source : null, alsoSaidGoogle: alsoSaidGoogle[month] ?? 0, people: [] });
  }
  const total = emptyRow();
  for (const m of byMonth.values()) {
    if (m.spend) total.spend = (total.spend ?? 0) + m.spend;
    total.alsoSaidGoogle += m.alsoSaidGoogle;
  }
  for (const p of people) {
    const row = byMonth.get(p.cohortMonth);
    if (!row) continue;
    addPerson(row, p);
    addPerson(total, p);
    row.people.push({ userId: p.userId, name: p.name, phoneLast4: p.phone10 ? p.phone10.slice(-4) : null, tier: p.tier, stage: furthestStage(p), feesPaid: p.feesPaid });
  }
  for (const m of byMonth.values()) setReturn(m);
  setReturn(total);
  return { months: [...byMonth.values()], total };
}

export function validateSpendInput(month: unknown, amount: unknown, currentMonth: string): string | null {
  if (typeof month !== 'string' || !/^\d{4}-(0[1-9]|1[0-2])$/.test(month)) return 'month must be YYYY-MM';
  if (month < ROI_FROM_MONTH) return `month must be ${ROI_FROM_MONTH} or later`;
  if (month > currentMonth) return 'month cannot be in the future';
  if (amount === null) return null;
  if (typeof amount !== 'number' || !Number.isFinite(amount) || amount < 0 || amount > 1_000_000) return 'amount must be a number from 0 to 10,00,000';
  return null;
}

/**
 * Database side of the Ads ROI page: who came from Google Ads, how far each of
 * them got, and what was spent. Counting lives in roi.ts.
 *
 * Lists are read in pages of 1,000 (PostgREST's row cap) and ids in chunks of
 * 100 (long .in() lists overflow the URL). A person is followed through every
 * account that shares their phone, because staff often enrol a student under a
 * second, phone-only account; their fees still belong to the ad that found them.
 */

import { isRealProspect, type UserForConversion } from './ads/conversions';
import { writeAudit } from './audit';
import { readAdsEnv, type AdsEnv } from './config';
import { isGoogleAdsTouch } from './funnel';
import { buildRoi, istMonth, monthsBetween, phone10, phoneVariants, ROI_FROM_MONTH, type RoiPerson, type RoiReport, type SpendEntry } from './roi';
import { loadEntityDays } from './store';

const PAGE = 1000;
const CHUNK = 100;
const SAMPLE_CUSTOMER = '1234567890';
const DEMO_DEAD = new Set(['cancelled', 'rejected']);
export const SPEND_KEY = 'spend_manual';

type UserRow = UserForConversion & { name: string | null };
type Credited = { u: UserRow; tier: RoiPerson['tier']; cohortMonth: string; p10: string | null };

async function pages(make: (from: number, to: number) => any): Promise<any[]> {
  const out: any[] = [];
  for (let offset = 0; ; offset += PAGE) {
    const { data, error } = await make(offset, offset + PAGE - 1);
    if (error) throw new Error(error.message);
    out.push(...(data ?? []));
    if (!data || data.length < PAGE) return out;
  }
}

async function chunked<T>(values: T[], fetch: (part: T[]) => any): Promise<any[]> {
  const out: any[] = [];
  for (let i = 0; i < values.length; i += CHUNK) {
    const { data, error } = await fetch(values.slice(i, i + CHUNK));
    if (error) throw new Error(error.message);
    out.push(...(data ?? []));
  }
  return out;
}

function push<K, V>(map: Map<K, V[]>, key: K, value: V) {
  const list = map.get(key);
  if (list) list.push(value);
  else map.set(key, [value]);
}

export async function loadRoiPeople(db: any, fromIso: string): Promise<{ people: RoiPerson[]; alsoSaidGoogle: Record<string, number> }> {
  const users: UserRow[] = await pages((a, b) =>
    db
      .from('users')
      .select('id, name, email, phone, phone_verified, user_type, first_touch, first_touch_at, created_at')
      .eq('phone_verified', true)
      .gte('created_at', fromIso)
      .order('id', { ascending: true })
      .range(a, b),
  );

  const answers = new Map<string, string>();
  const { data: question, error: qErr } = await db.from('onboarding_questions').select('id').eq('question_key', 'referral_source').maybeSingle();
  if (qErr) throw new Error(qErr.message);
  if (question) {
    const rows = await pages((a, b) => db.from('onboarding_responses').select('user_id, response').eq('question_id', question.id).order('id', { ascending: true }).range(a, b));
    for (const r of rows) if (r.user_id && r.response?.value) answers.set(r.user_id, String(r.response.value));
  }

  const candidates: Credited[] = [];
  const alsoSaidGoogle: Record<string, number> = {};
  for (const u of users) {
    if (!isRealProspect(u)) continue;
    const p10 = phone10(u.phone);
    if (isGoogleAdsTouch(u.first_touch)) {
      candidates.push({ u, tier: 'confirmed', cohortMonth: istMonth(u.first_touch_at ?? u.created_at), p10 });
      continue;
    }
    const said = answers.get(u.id);
    if (said === 'google_ad') candidates.push({ u, tier: 'said_google_ad', cohortMonth: istMonth(u.created_at), p10 });
    else if (said === 'google') {
      const m = istMonth(u.created_at);
      alsoSaidGoogle[m] = (alsoSaidGoogle[m] ?? 0) + 1;
    }
  }

  // One phone, one credit: the confirmed account first, then the earliest.
  candidates.sort((a, b) => (a.tier === b.tier ? a.u.created_at.localeCompare(b.u.created_at) : a.tier === 'confirmed' ? -1 : 1));
  const seenPhones = new Set<string>();
  const credited = candidates.filter((c) => {
    if (!c.p10) return true;
    if (seenPhones.has(c.p10)) return false;
    seenPhones.add(c.p10);
    return true;
  });
  if (!credited.length) return { people: [], alsoSaidGoogle };

  const phones = [...seenPhones];
  const variants = phones.flatMap(phoneVariants);
  const twins = await chunked(variants, (part) => db.from('users').select('id, phone').in('phone', part));
  const idsByPhone = new Map<string, string[]>();
  for (const t of twins) {
    const p = phone10(t.phone);
    if (p) push(idsByPhone, p, t.id);
  }
  const idsOf = (c: Credited) => new Set([c.u.id, ...(c.p10 ? idsByPhone.get(c.p10) ?? [] : [])]);
  const allIds = [...new Set(credited.flatMap((c) => [...idsOf(c)]))];

  const demosById = await chunked(allIds, (part) => db.from('demo_class_registrations').select('id, user_id, phone, status, attended').in('user_id', part));
  const demosByPhone = await chunked(variants, (part) => db.from('demo_class_registrations').select('id, user_id, phone, status, attended').in('phone', part));
  const students = await chunked(allIds, (part) => db.from('student_profiles').select('id, user_id').in('user_id', part));
  const spByUser = new Map<string, string[]>();
  for (const s of students) push(spByUser, s.user_id, s.id);
  const payById = await chunked(allIds, (part) => db.from('payments').select('id, amount, user_id, student_profile_id').eq('status', 'paid').in('user_id', part));
  const payBySp = await chunked(
    students.map((s) => s.id),
    (part) => db.from('payments').select('id, amount, user_id, student_profile_id').eq('status', 'paid').in('student_profile_id', part),
  );
  const payments = new Map<string, any>();
  for (const p of [...payById, ...payBySp]) payments.set(p.id, p);

  const people: RoiPerson[] = credited.map((c) => {
    const ids = idsOf(c);
    const demos = [...demosById, ...demosByPhone].filter((d) => ids.has(d.user_id) || (c.p10 && phone10(d.phone) === c.p10));
    const live = demos.filter((d) => !DEMO_DEAD.has(String(d.status)));
    const sps = new Set([...ids].flatMap((id) => spByUser.get(id) ?? []));
    let feesPaid = 0;
    for (const pay of payments.values()) if (ids.has(pay.user_id) || sps.has(pay.student_profile_id)) feesPaid += Number(pay.amount) || 0;
    return {
      userId: c.u.id,
      name: c.u.name ?? null,
      phone10: c.p10,
      tier: c.tier,
      cohortMonth: c.cohortMonth,
      demoBooked: live.length > 0,
      demoAttended: live.some((d) => d.attended === true),
      joined: sps.size > 0,
      feesPaid,
    };
  });
  return { people, alsoSaidGoogle };
}

export async function loadManualSpend(db: any): Promise<Record<string, number>> {
  const { data, error } = await db.from('marketing_ai_settings').select('key, value').eq('key', SPEND_KEY).maybeSingle();
  if (error) throw new Error(error.message);
  const out: Record<string, number> = {};
  const value = data?.value;
  if (value && typeof value === 'object') for (const [m, n] of Object.entries(value)) if (typeof n === 'number' && Number.isFinite(n)) out[m] = n;
  return out;
}

export async function saveManualSpend(db: any, month: string, amount: number | null, adminId: string): Promise<Record<string, number>> {
  const before = await loadManualSpend(db);
  const after = { ...before };
  if (amount === null) delete after[month];
  else after[month] = amount;
  const { error } = await db.from('marketing_ai_settings').upsert({ key: SPEND_KEY, value: after, updated_by: adminId, updated_at: new Date().toISOString() }, { onConflict: 'key' });
  if (error) throw new Error(error.message);
  await writeAudit(db, { actor: { type: 'admin', id: adminId }, event: 'spend_manual_set', entityType: 'month', entityId: month, before: { amount: before[month] ?? null }, after: { amount } });
  return after;
}

export async function loadSpend(db: any, fromMonth: string, toDate: string, env: AdsEnv = readAdsEnv()): Promise<Record<string, SpendEntry>> {
  const out: Record<string, SpendEntry> = {};
  for (const [m, amount] of Object.entries(await loadManualSpend(db))) out[m] = { amount, source: 'manual' };
  if (env.mode === 'live' && env.customerId && env.customerId !== SAMPLE_CUSTOMER) {
    const rows = await loadEntityDays(db, env.customerId, `${fromMonth}-01`, toDate, ['campaign']);
    const live: Record<string, number> = {};
    for (const r of rows) live[r.date.slice(0, 7)] = (live[r.date.slice(0, 7)] ?? 0) + r.cost_micros / 1e6;
    for (const [m, amount] of Object.entries(live)) out[m] = { amount: Math.round(amount), source: 'google' };
  }
  return out;
}

export async function loadRoi(db: any, now = new Date()): Promise<RoiReport> {
  const today = new Date(now.getTime() + 5.5 * 3600 * 1000).toISOString().slice(0, 10);
  const months = monthsBetween(ROI_FROM_MONTH, today.slice(0, 7));
  const [{ people, alsoSaidGoogle }, spend] = await Promise.all([loadRoiPeople(db, `${ROI_FROM_MONTH}-01T00:00:00+05:30`), loadSpend(db, ROI_FROM_MONTH, today)]);
  return buildRoi(people, spend, alsoSaidGoogle, months);
}

export async function PUT(request: NextRequest) {
  const guard = requireAdminRole(request);
  if (!guard.ok) return guard.response;
  try {
    const { month, amount } = await readJson(request);
    const currentMonth = new Date(Date.now() + 5.5 * 3600 * 1000).toISOString().slice(0, 7);

    return NextResponse.json({ spend });
  } catch (err) {
    return errorResponse(err, 'roi spend');

                        onClick={() => setOpen({ month: m, metric: c.key })}

          <Box>
            <Box sx={{ display: 'flex', alignItems: 'center', justifyContent: 'space-between', mb: 2 }}>

                {COLUMNS.find((c) => c.key === open.metric)!.label}, {monthName(open.month.month)}
              </Typography>
              <IconButton aria-label="Close" onClick={() => setOpen(null)} sx={TARGET_44}><CloseIcon /></IconButton>
            </Box>
            {people.map((p) => (
              <Box key={p.userId} sx={{ py: 1.5, borderBottom: 1, borderColor: 'divider' }}>
                <Typography variant="body1">{p.name || 'No name'}{p.phoneLast4 ? `, phone ending ${p.phoneLast4}` : ''}</Typography>
                <Typography variant="body2" color="text.secondary">
                  {p.tier === 'confirmed' ? 'Ad click' : 'Said ad'} · {STAGE_LABEL[p.stage]}{p.feesPaid > 0 ? ` · paid ${inr(p.feesPaid)}` : ''}
                </Typography>
              </Box>
            ))}
          </Box>
        )}
      </Drawer>

      <Snackbar open={!!toast} autoHideDuration={5000} onClose={() => setToast(null)} message={toast} />
    </Box>
  );
}

- [ ] **Step 1: Write the migration** (idempotent; it inserts the option right after `google`)

```sql
-- Ads ROI: a separate "Google ad" answer to "How did you find Neram Classes?",
-- so a sponsored result can be told from free search. Plain "Google Search"
-- answers are about 55 to 60% every month, ads or not, so they cannot be
-- credited to ads. Existing answers are untouched.
update onboarding_questions q
set options = (
  select jsonb_agg(s.elem order by s.ord)
  from (
    select t.elem, t.ord::numeric as ord
    from jsonb_array_elements(q.options) with ordinality as t(elem, ord)
    union all
    select '{"value":"google_ad","label":"Google ad (Sponsored result)","label_ta":"கூகுள் விளம்பரம்","icon":"search"}'::jsonb,
           coalesce((select g.ord + 0.5 from jsonb_array_elements(q.options) with ordinality as g(elem, ord) where g.elem->>'value' = 'google'), 1000)
  ) s
)
where q.question_key = 'referral_source'
  and not q.options @> '[{"value":"google_ad"}]'::jsonb;
```
